# ゲームパッド入力の廃止 — intent

## 背景
ユーザー判断で、このゲームの操作はゲームパッドを使わないことになった(2026-10-01)。マウス(とキーボード)で操作する。

## 現状
- `Game::Update()` などに `g_pad[0]` のボタン(A/B/X/Y/LB1/RB1/十字/Start/Back/LT 等)による操作が多数ある。フォーカス(どの一覧を操作中か)・一覧カーソル・ヘックスカーソルといった、パッド操作のための状態や表示も存在する。
- k2Engineは、パッド未接続時にキーボードを`g_pad`へ割り当てている可能性がある(ヘルプのLT代替が「Nキー」等)。
- UIのラベルにパッドのボタン名が書かれている箇所がある(例: 戦闘開始ボタン「戦闘開始 [B]」)。
- ヘルプ(`Game/HelpContent.cpp`)の「操作」カテゴリにパッドの操作一覧がある。

## 要求仕様
1. `g_pad` 経由の入力による操作をゲームから取り除く。マウスで同じことができる操作は、マウスだけで完結するようにする。
   - マウスで代わりができない操作(例: タイトル画面からの開始、結果画面からの続行、セーブ等)があれば、マウスのクリック(画面クリックやボタン)か、キーボードのキーを直接読む形で代わりの手段を用意する。
   - パッドのためだけに存在するフォーカス・一覧カーソル・ヘックスカーソル等の状態・表示・処理は、不要になれば取り除く(マウスのホバー表示などで使われているものは残す)。
2. キーボードのショートカットは、`g_pad`を経由せずキーを直接読むものだけ残してよい(ヘルプのF1/Esc 等)。`g_pad`経由でしか動かないキーボード操作は、必要なものだけ直接キー入力に置き換え、不要なら削除する。
3. UIのラベルからパッドのボタン名(`[B]`等)を消す。キーボードのショートカットが残る場合はそのキー名を書いてよい。
4. ヘルプの「操作」カテゴリを、マウス(クリック・右クリック・ドラッグ&ドロップ)とキーボードショートカットだけの説明に書き直す。ヘルプの開閉方法からもパッドを消す。
5. ついでに対応: リロールコスト(2G)が `Game.cpp` に手書き定数として2か所あるので、`ShopSystem::kRerollCost` に寄せる。

## 受け入れ条件
- Debug x64でビルドが通る。
- ゲームの開始から終了(勝利/ゲームオーバー/リトライ)まで、ゲームパッド無しで全ての操作ができる。
- 画面上やヘルプにパッドのボタン名が残っていない。
