# 合成・売却時の装備アイテム引き継ぎ — intent

## 背景
現状、ユニットを合成(同じユニット3体で星アップ)したり売却したりすると、そのユニットが装備していたアイテムが消える。ユーザー判断でこの仕様を解消する(2026-10-01)。

## 要求仕様(ユーザー決定済み)
1. **合成時**: 合成の素材になった3体が装備していたアイテムを、すべて合成後のユニットに引き継ぐ。
   - 1体あたりの装備上限(現状3つ)を超える分は、プレイヤーの未装備アイテム一覧(`player.unclaimedItems`)に戻す。
   - 引き継ぎ時、素材アイテム同士の自動合成など、既存の装備ルール(`ItemSystem`)があればそれに従う。どの順で装備するかは、合成後に残る1体の既存装備→他の2体の装備の順でよい。
   - 星2→星3の合成(星2が3体)でも同様。
2. **売却時**: 売ったユニットが装備していたアイテムを、すべて未装備アイテム一覧に戻す。ベンチからの売却・盤面からの売却・ドラッグ&ドロップでの売却のすべてで同じ挙動にする。
3. 盤面からベンチへ戻すだけの操作では、装備はユニットに付いたまま(現状維持)。
4. アイテムが未装備一覧に戻った/引き継がれたことが分かるよう、既存のフィードバック(`PushFeedback`)かログで知らせる(例: 「装備をアイテム欄に戻しました: ○○」)。
5. ヘルプ(`Game/HelpContent.cpp`)の「装備は合成・売却で消える」旨の注意書きを、新しい仕様に合わせて書き直す。

## 受け入れ条件
- Debug x64でビルドが通る。
- 合成で装備が失われず、上限超過分は未装備一覧に戻る。
- 売却で装備が未装備一覧に戻る(すべての売却経路で)。
