# 連勝ボーナス強化 — intent

## 背景
2026-10-01のプレイテストで「連勝にうまみがなく、わざと2敗してから勝つ戦術でゴールドを稼ぐ方が強く、不健全」という指摘があった。
連勝を続けるほど得をするようにボーナスを強化する(Notionタスク I)。

## 現状
- `Game/EconomySystem.h` の `GetStreakBonus` で、連勝・連敗とも同じ表を使っている: 2で+1、3〜4で+2、5以上で+3。
- 勝利すると毎回、素材アイテムを1つ入手する(`Game::ApplyCombatOutcome`、Game.cpp)。
- 負けてもラウンドは進まない(同じ敵に3敗でゲームオーバー)。

## 要求仕様(ユーザー決定済み)
1. **連勝ボーナス(ゴールド)**: 2連勝で+10、3連勝で+15、4連勝で+20…と、1連勝ごとに+5ずつ増える。上限は設けない(式: 連勝数n≥2なら 5n)。
2. **連敗ボーナス**: 現状のまま(2で+1、3〜4で+2、5以上で+3)。連勝と連敗で別々の表にする。
3. **連勝アイテム報酬**: 5連勝以上では、勝つたびに通常の勝利報酬に加えて素材アイテムをもう1つもらえる(合計2個)。
4. 追加のアイテム入手は、通常の勝利報酬と同じように画面のフィードバック(`PushFeedback`)とデバッグログに出す。連勝ボーナス由来だとわかる文言にする(例: 「連勝ボーナス: ○○」)。
5. 負けたときの扱い(基本収入・利子・ラウンドが進まない仕様)は変えない。

## 受け入れ条件
- Debug x64でビルドが通る。
- 収入ログ(`[...] Income: ...`)の連勝ボーナス額が上の式どおりになる。
- 5連勝目以降の勝利で、アイテムが2個入手できる。4連勝目までは1個。
- 画面上に連勝ボーナスの額や仕様を表示している箇所(HUD・ツールチップ・説明文など)があれば、新しい数値と食い違わないよう合わせて更新する。
