# 要件定義: デバッグ用の合成ロジック確認コードの整理

- Notionタスク: 「デバッグ用の合成ロジック確認コードの整理」(期限 2026-09-17)
- 担当: 実装用セッション / 依頼元: マネージャー

## 背景・現状

- `Game::Start()` の末尾に、合成ロジック(`Player::TryMergeUnits`)の動作確認専用のデバッグ初期化コードが残っている。
  - 内容: `UnitDatabase` から "Slime" を引き、`players[0].bench` に Slime を3体 push、`while (player.TryMergeUnits()) {}` で
    ★2の Slime 1体へ自動合成させ、合成後のベンチ数を `[DEBUG]` プレフィックス付きで `OutputDebugString` に出す。
  - 該当: `Game/Game.cpp` の `Game::Start()` 内、`// --- デバッグ用: 合成ロジックの動作確認。` コメントから
    `OutputDebugString(mergeLogBuf);` まで(コメント含め該当ブロック)。加えて、このブロック専用に取得している
    `Player& player = m_gameState.players[0];` の行。
- ショップUI・盤面配置UI・アイテム取得/装備導線など、合成の動作を通常プレイで確認できる関連機能は既に実装済み。
  よってこのデバッグ初期化コードはもう不要で、削除するだけでよい。

## 目的

`Game::Start()` からデバッグ専用の合成確認コードを取り除き、ゲーム開始時のベンチを本来の空の状態に戻す。

## 要求仕様

1. 該当デバッグブロック(Slimeベンチ追加 + `while (TryMergeUnits())` + `[DEBUG]` ログ出力)を削除する。
2. ブロック専用にしか使われなくなる `Player& player = m_gameState.players[0];` も併せて削除する
   (未使用ローカル変数を残さない)。
3. `Game.cpp` に他の「デバッグ用」「検証用」等の暫定コードが残っていないか目視確認し、見つかれば報告する
   (対応要否はマネージャー判断)。

## 受け入れ条件

- ビルドが通る(Debug/x64、VS 2026 の v145 ツールセット、警告を増やさない)。
- ゲーム開始時、`players[0].bench` が空で始まる(Slime 3体 → ★2 が自動で入っていない)。
- 通常プレイフロー(ショップ購入 → ベンチ配置 → 同ユニット3体で自動合成)は従来どおり動作する
  (合成ロジック自体は変更しないため影響しない想定)。

## スコープ外

- `Player::TryMergeUnits` など合成ロジック本体には手を入れない。
- 通常の状態遷移ログ(`OutputDebugString` による各種ログ)はこのゲームの設計上の表示手段であり、
  デバッグ用暫定コードではないため削除対象にしない。
