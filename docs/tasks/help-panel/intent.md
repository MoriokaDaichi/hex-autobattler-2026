# ヘルプボタンとカテゴリ別説明 — intent

## 背景
2026-10-01のプレイテストで「要素が多いので、ヘルプボタンを追加して、経済・戦闘・アイテムなど項目を分けて各要素の説明を見られるようにするべき」という指摘があった(Notionタスク K)。説明文の内容は実装者に任されている(ユーザー了承済み)。

## 要求仕様
1. 画面上の邪魔にならない位置(例: 画面右上や左上の隅)に「ヘルプ」ボタンを置く。クリック(と、可能ならキーボード/パッドの空いているボタン)で開閉する。
2. 開くと画面中央にパネルが出て、左側(または上部)のカテゴリタブで内容を切り替えられる。閉じるボタンもある。
3. カテゴリと内容(いずれも現在のゲームの実際の仕様をコードから確認して書くこと。数値は定数から正しく書く):
   - **基本の流れ**: 準備→戦闘→結果の流れ、勝利でラウンドが進む、同じ敵に3敗でゲームオーバー、全ラウンドクリアで勝利。
   - **操作**: マウス(クリック・右クリック・ドラッグ&ドロップ ※別タスクで追加中なので「ドラッグでも移動・装備・売却できる」程度に一般的に書いてよい)とゲームパッドの操作一覧。
   - **経済**: 基本収入・利子(10Gごとに+1、上限)・連勝/連敗ボーナス(連勝は2連勝+10、以降+2ずつ。連敗の表)・5連勝以上でアイテム追加・リロール/経験値購入のコスト・ショップロック。
   - **ユニットと★**: ショップでの購入、同じユニット3体で★2、★2を3体で★3、盤面の配置上限とレベル。
   - **戦闘**: 自動戦闘、移動と攻撃、必殺技ゲージ(通常攻撃と被弾で溜まる)、物理/魔法、防御。
   - **アイテム**: 勝利報酬での入手、装備方法、素材アイテムの合成(合成レシピがあれば主なもの)、装備上限。
   - **トレイト**: 盤面に同じトレイトのユニットを揃えると発動、段階、主なトレイトの効果(データベースから)。
4. 1カテゴリの文章がパネルに収まらない場合は、ページ送りかスクロールで読めるようにする。
5. 既存フォントにない漢字は「?」になるため、使う文字に注意する(既存UIで使われている漢字を優先し、怪しい語は平易な言い換えかカタカナにする)。
6. ヘルプを開いている間は、パネル外のクリックで盤面などが操作されないようにする。どのフェーズでも開けてよいが、戦闘の進行は止めなくてよい。

## 受け入れ条件
- Debug x64でビルドが通る。
- ヘルプボタンで開閉でき、カテゴリを切り替えて全カテゴリの説明が読める。
- 説明の数値がコード上の実際の値と一致している。
