# 戦闘中の数字表示の重なり解消 — intent

## 背景
2026-10-01のプレイテストで「戦闘中、ダメージなどの数字の表示が重なって見づらい」という指摘があった(Notionタスク G)。

## 現状
- 戦闘はシミュレーション後に `CombatPlayback`(Game/CombatPlayback.*)で時系列再生している。
- 再生中にダメージ・回復などの数字がユニット付近に表示されるが、同じユニットに短い間隔で複数のイベントが起きると数字が同じ位置に重なり、読めなくなる。

## 要求仕様
- 同じユニット付近で同時期に出る数字が重ならず、読めるようにする。手法は実装者に任せるが、例えば次のような組み合わせ:
  - 時間とともに上へ流れてフェードアウトする(既にあれば速度・寿命を調整)。
  - 同じユニットで直近に出た数字と重なる場合は、縦(または横)に少しずらして積む。
  - 種類ごとに色や大きさを分け、重要な数字(必殺技・大ダメージ・撃破)を目立たせる。
- 同時表示数が多すぎる場合は、古いものから消す、または短時間の連続ダメージを合算する、などで抑える。
- 戦闘の結果やシミュレーション(CombatEngine)は変更しない。表示だけの変更とする。

## 受け入れ条件
- Debug x64でビルドが通る。
- 多数のユニットが同時に攻撃し合う場面でも、数字が重なって読めない状態にならない。
- 既存の戦闘再生(移動・アニメーション・HPバー)を壊していない。
