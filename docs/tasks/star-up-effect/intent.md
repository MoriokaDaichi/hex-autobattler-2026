# ★アップ演出 — intent

## 背景
2026-10-01のプレイテストで「ユニットが3体・9体集まって星が上がったときに演出(エフェクトなど)を追加するべき」という指摘があった(Notionタスク L)。

## 現状
- 同じユニット・同じ星が3体そろうと `Player::TryMergeUnits` が自動で合成する(星1→星2、星2→星3。購入・配置・ドラッグ等で盤面/ベンチが変わるたびにチェック)。合成時は装備を引き継ぎ、`itemNotices` でフィードバックを出している。
- 星に応じてモデルのスケールが少し大きくなる(`UnitModelDisplay` の `GetStarModelScaleMultiplier`)以外、合成の瞬間の演出は無い。
- エンジンには Effekseer が組み込まれている(`k2EngineLow/ExEngine` 配下、エンジン側にエフェクト再生のラッパーがある可能性)。エフェクト素材(.efk等)がプロジェクトにあるかは未確認。

## 要求仕様(ユーザー決定済み)
1. 合成で星が上がった瞬間に、合成後のユニット(盤面ならそのマス、ベンチならベンチの表示位置)で演出を出す。
2. **星2は控えめ、星3は派手**にする。
3. **演出に一貫性を持たせる**: 星2と星3で同じモチーフ(同じ要素の組み合わせ・同じ色系統・同じ動きの型)を使い、星3はその規模・数・時間・明るさを強めたもの+αにする。別物の演出にしない。
   - 例: 共通 = 足元から光のリング/光の柱が立ち上がり、ユニットが一瞬拡大して戻る(ポップ)。星2 = 小さく短く1回。星3 = 大きく長く、リングを多重にし、粒子を多めに、画面に短いフラッシュや揺れを足す。
4. 演出中も操作は止めない(準備フェーズの操作を妨げない)。連続で合成が起きても破綻しない(星1→2→3の連鎖合成では星3の演出が見えればよい)。
5. 既存のエフェクト素材があれば活用し、無ければ既存の描画手段(モデル・スプライト・矩形/ライン描画・スケールアニメ等)で自作する。サードパーティ(ExEngine)は変更しない。
6. 合成成立時のフィードバック文(例: 「★2に合成!」)があるなら、星の表記はフォントにある文字(「星2」「*2」など)を使う。

## 受け入れ条件
- Debug x64でビルドが通る。
- 星2合成・星3合成でそれぞれ演出が出て、星3の方がはっきり派手に見え、かつ同じ系統の演出だと分かる。
- 演出中もゲームの操作・進行に影響しない。
