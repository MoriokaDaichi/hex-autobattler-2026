# ドラッグ&ドロップ操作 — intent

## 背景
2026-10-01のプレイテストで「ベンチ→盤面、盤面→ベンチ、アイテム→ユニットなどの操作がクリックに割り当てられていて直感的でない。ドラッグ&ドロップにするべき」という指摘があった(Notionタスク J)。

## 現状
- 準備フェーズのマウス操作は、クリックで対象を選んでからクリックで行き先を指定する方式(UIHotRegion / m_uiInteraction、Game.cpp)。
- ゲームパッド操作(g_pad[0])も残っている。

## 要求仕様
1. マウスの左ボタンを押したまま動かすとドラッグを開始し、離した場所で処理を確定する。
   - ベンチのユニット → 盤面の空きマス: 配置。盤面のユニットがいるマス: 入れ替え(既存に入れ替え処理があれば使う。無ければ、ドラッグしてきたユニットとそのマスのユニットの位置を入れ替える)。
   - 盤面のユニット → 盤面の別マス: 移動(相手がいれば入れ替え)。
   - 盤面のユニット → ベンチ領域: ベンチへ戻す(既存の「ベンチへ戻す」と同じ。ゴールドは増えない)。
   - 未装備アイテム → 盤面/ベンチのユニット: 装備(既存の装備ルール・合成・上限に従う)。
   - ベンチ/盤面のユニット → ショップ領域: 売却(既存の売却処理と同じ。TFTと同じ操作感)。
2. ドラッグ中は、掴んでいるもの(ユニット名やアイテム名などの簡単な表示で可)がカーソルに追従し、ドロップ先の候補(マス・ユニット・ベンチ・売却領域)がハイライトされる。
3. 無効な場所で離した場合は何も起こらず元に戻る。盤面の配置上限を超える配置など、既存のルールで拒否される操作は、既存と同じフィードバックを出す。
4. 押して少ししか動かさずに離した場合は、従来のクリック扱いとし、既存のクリック操作も壊さない(ドラッグは追加の手段)。
5. ゲームパッド操作は変更しない。
6. 準備フェーズのみ。戦闘中はドラッグできない。

## 受け入れ条件
- Debug x64でビルドが通る。
- 上記のドラッグ操作がすべて機能し、既存のクリック/右クリック/パッド操作が引き続き使える。
- 合成(同じユニット3体で★アップ)など、盤面・ベンチの変化に伴う既存の処理が、ドラッグ経由でも正しく走る。
