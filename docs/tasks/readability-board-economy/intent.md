# 見やすさ改善: 盤面サイズ・収入内訳 — intent

## 背景
2026-10-01のプレイテストで出た指摘のうち、見やすさに関する2件(Notionタスク F・H)をまとめて対応する。
戦闘中の数字の重なり(G)は別タスク `docs/tasks/combat-number-overlap/` で並行対応する。

## F. 盤面が小さく見づらい・操作しづらい
- 現状: 画面中央の盤面(ヘックスグリッドとユニット)が小さく、見づらく操作もしづらい。
- 要求: カメラの位置・画角(必要ならUIの配置も)を調整し、盤面を画面上で大きく表示する。
  - 自陣・中立・敵陣(r:0〜8)と、ベンチがすべて画面内に収まること。
  - ショップ・HUD・戦闘開始ボタン(画面右下)など既存UIと盤面が重ならないこと。UIを動かす必要があればそれも行う。
  - マウスでのヘックス判定(クリック・ホバー)がカメラ変更後も正しく動くこと。

## H. 収入の内訳表示
- 現状: 利子や基本収入などの経済面の情報が画面にほとんど出ていない。
- 要求: HUDのゴールド表示にマウスを乗せると、次のラウンドでもらえるゴールドを項目ごとに表示するツールチップを出す。
  - 項目: 基本収入、利子(現在の所持金から計算。上限も分かるように)、連勝/連敗ボーナス(勝った場合・負けた場合それぞれ)、合計。
  - 計算は `EconomySystem` と同じ定数・関数を使い、実際の収入とずれないこと(必要なら EconomySystem に計算用の関数を切り出す)。
  - 次の利子段階まであと何Gか、のような補足があるとなお良い。
  - 既存のツールチップの仕組み(`TooltipContentBuilder`・UIHotRegion)に合わせる。

## 受け入れ条件
- Debug x64でビルドが通る。
- F: 盤面が従来より明確に大きく表示され、盤面・ベンチ・UIが重ならず、マウス操作が正しく動く。
- H: ゴールド表示へのホバーで内訳が表示され、実際のラウンド終了時の収入ログ(`Income:`)と一致する。
