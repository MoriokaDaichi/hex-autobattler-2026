# 要件定義: 盤面内再配置（盤面上のユニット移動・ベンチへ戻す操作）

## 背景・現状

- `Player::PlaceUnitOnBoard(benchIndex, targetPos)` は **ベンチ → 盤面** の一方向のみ。
  一度盤面に置いたユニットを、別のマスへ動かす手段も、ベンチへ戻す手段も無い。
- 準備フェーズの操作は `Game::Update()` の Preparation ブロックがゲームパッド
  A/B/X/Y/LB1/RB1 を直接判定して駆動する。対象（どのマス／どのリスト要素）は
  `CursorSelectionSystem`（`InputFocus` = Shop / Bench / Items / Board、Tab または
  Select で巡回）が提供する。盤面フォーカス時のヘックスカーソルはマウスホバー／
  矢印キー／D-pad で動く。
- 既存のボタン割り当て（Preparation）:
  | ボタン | 動作 |
  |---|---|
  | A | ユニット購入 / アイテムを手に持つ / 手持ちアイテムを選択中ユニットへ装備 |
  | B | 戦闘フェーズへ進む |
  | X | ベンチのユニットを盤面へ配置（Bench フォーカス時はカーソル、それ以外はベンチ先頭。配置先はヘックスカーソル） |
  | Y | ショップをリロール |
  | LB1 | ベンチのユニットを売却（Bench フォーカス時はカーソル、それ以外は先頭） |
  | RB1 | 経験値購入 |
- アイテム装備は「Items フォーカスで A → アイテムを"手に持つ"（`m_heldUnclaimedIndex`）→
  Bench/Board フォーカスでユニットを選び A → 装備確定」という2段階の"手に持つ"モデルで実装済み。
  盤面内再配置もこのパターンを踏襲する。

## 目的

準備フェーズで、盤面に配置済みのユニットを

1. **別の空いている自陣マス（q0〜2）へ移動できる**
2. **ベンチへ戻せる**

ようにする。既存のベンチ→盤面配置・購入・売却・装備の操作は一切変えない。

## 要求仕様

### 操作（`CursorSelectionSystem` の"手に持つ"モデルを踏襲）

- Board フォーカス中、ヘックスカーソルが **自分の盤面ユニットが居るマス** を指した状態で **X**
  → そのユニットを「移動元」として選択（"手に持つ" 相当。`m_heldBoardHex`）。
- 移動元を選択した状態で、ヘックスカーソルを **空いている自陣マス（q0〜2）** に合わせて **X**
  → そのマスへ移動。移動元選択は解除。
- 移動元を選択した状態で、**同じマス**（移動元）を指して **X** → 選択解除（キャンセル）。
- Board フォーカス中、対象（移動元を選択中ならそれ、未選択ならヘックスカーソルのユニット）が
  盤面ユニットのとき **LB1** → そのユニットをベンチへ戻す。移動元選択は解除。
- フォーカスが Board から外れたら移動元選択は自動解除。戦闘フェーズ突入（B）・リスタートでも解除。

### ルール

- 移動先は自陣（q0〜2）のみ。中立（q3〜5）・敵陣（q6〜8）へは移動不可。
  （r 範囲・q≤8 はヘックスカーソルが有効マスを保証している前提で、既存 `PlaceUnitOnBoard` と同様チェックしない）
- 移動先が他ユニットで埋まっている場合は移動不可。
- 盤面内移動では盤面ユニット数が増減しないため、レベル上限（`GetMaxBoardSize`）チェックは不要。
- ベンチへ戻す操作にベンチ枚数上限は設けない（既存 `BuyUnit` もベンチ上限を設けていないため整合させる）。
- 移動・ベンチ戻しで `homePosition` を新しい位置に更新する（毎ラウンド戦闘開始前に戻る先）。
- 失敗時は既存同様 `m_shopUI.PushFeedback()` と `OutputDebugString` で通知する。

## 受け入れ条件

1. `msbuild Game/Game.sln /p:Configuration=Debug /p:Platform=x64` がビルド成功する。
2. 実機（F5）で、盤面に2体以上配置した状態から:
   - 盤面ユニットを選択し、空いている自陣マスへ移動 → 3D表示・内部状態とも移動する。
     フィードバック「移動: (q,r) -> (q,r)」（矢印は全角不可・FontEngine制約のためASCII）。
   - 移動先に中立／敵陣マスを指定 → 失敗。フィードバックに「自陣 q0-2 のみ」。
   - 移動先に他ユニットが居るマスを指定 → 失敗。フィードバックに「空きマス無し」。
   - 盤面ユニットを選択し LB1 → ベンチへ戻る（3D表示から消え、BENCH 一覧に追加）。
   - ベンチへ戻したユニットを再度 X（Bench→Board 配置）で盤面へ出せる。
3. 既存操作（購入・リロール・売却・装備・ベンチ→盤面配置・戦闘へ進む）が従来通り動く。
4. `plan.md` の設計と実装が一致している。

## スコープ外

- 盤面上での「移動元選択中」の永続的なビジュアル表示（ハイライト）。現状の盤面 UX は
  ヘックスカーソル自体の常時ハイライトも持たないため、本タスクでもテキストフィードバック＋
  デバッグログに留め、ハイライトは将来のフォローアップとする。
- ドラッグ＆ドロップ操作。
- ベンチ内の並び替え。
