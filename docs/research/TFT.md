調査日: 2026-08-27。調査担当: 外部調査用サブエージェント。目的: このプロジェクト(TFT風ヘックスグリッドオートバトラー)の実装参考。

## 1. OP.GG等のデータ構造(ユニット/アイテム/特性)

### ユニット(Champion)のデータ項目

- **コストティア**: $1〜$5。プールの希少度・ショップ出現率・強さがこれで決まる
- **特性タグ**: 各ユニットは「Origin(出自)」系1〜2個＋「Class(役割)」系1個の**特性タグを複数持つ**。このタグ数がそのままシナジー計算のカウントになる
- **スター**: 1〜3★(Set 15以降の一部は4★も)。同じユニット同スター3体で1段上に自動合成
- **スキル**: スキル名／アイコン／必要マナ(初期マナ・最大マナ)／`1★/2★/3★`の3段階で書かれたダメージ・効果値／条件付き効果テキスト
- **ステータスのスター補正(重要)**: 公式Wikiより
  - HP: 1★=100% → 2★=180% → 3★=324%(1.8倍ずつ)
  - AD: 1★=100% → 2★=150% → 3★=225%(1.5倍ずつ)
  - AS(攻撃速度)・射程・Armor・MRはスターで**変わらない**のが基本
- 基礎ステータスは HP / AD / AS / DPS / 射程(ヘックス数)/ Armor / MR / マナ(初期・最大)

### アイテムのデータ構造

- **コンポーネント(素材)9種**、各1ステータスを付与:
  - B.F. Sword=AD / Recurve Bow=AS / Needlessly Large Rod=AP / Tear of the Goddess=マナ / Chain Vest=Armor / Negatron Cloak=MR / Giant's Belt=HP / Sparring Gloves=クリティカル/回避 / Spatula=特殊(特性エンブレム用)
- **完成品 = 素材2個の組み合わせで決定論的に決まる**(9×9の対称行列＝**45種**の完成アイテム)
- 表示内容: 必要な素材2個 ＋ ステータス加算 ＋ パッシブ効果テキスト(Burn/Wound/Shred等の状態異常キーワード付き)
- **1ユニットにつきアイテム3スロット**。素材を乗せた上にもう1個乗せると自動合成
- **Spatula系＝エンブレム**: ユニットに乗せるとそのユニットに特性タグを1個追加できる(シナジー数を人工的に増やす)

### 特性(Trait / シナジー)のデータ構造

- 項目: アイコン／名前／所属ユニット一覧(ポートレート)／**ブレイクポイント(発動人数)**／各ブレイクポイントの効果値
- ブレイクポイントは `(3)/(5)/(7)` や `(2)/(4)/(6)` のように**段階制**。人数が閾値に達するたびに効果が段階的に強化される
- 効果は「発動ユニット全体へのステータス%バフ」型と「特殊メカニクス(例: 10秒後に最低HP敵を処刑、3.5秒ごとに繰り返す)」型がある
- 例(Set 18):
  - Blossom(8体): (3) 12% AP → (5) 30% AP＋全ショップに対象出現 → (7) 40% AP＋購入で4ゴールド
  - Sprykin(6体): (3) HP+15%/AS+15% → (5) HP+40%/AS+35% → (7) HP+45%/AS+45%

## 2. ゲーム画面のUI構成

画面レイアウト(tft.ninja「The Board」等より):

- **中央: ヘックス盤面** 4行×7列＝28ヘックス。自軍は手前半分にのみ配置可
- **盤面下: ベンチ** 9スロット(戦闘に参加しない控え)
- **最下部: ショップバー** ランダム5体を表示。各カードにコスト表示。**リロールボタン(2ゴールド)**＋**ロックボタン**(自動リロール防止)
- **下中央: リソース表示** 現在ゴールド／**XPバー＋「XP購入」ボタン(4ゴールドで4XP)**／自分のHPバー(100スタート)／現在レベル
- **左側: 特性パネル** 全特性を縦列表示。**発動中の特性はハイライトされ上部にソート、未発動は下にディム表示**。各行に現在人数／次のブレイクポイント閾値
- **右側: アイテムベンチ** 未装着の素材・完成品を保持
- **右上: ミニマップ/スコアボード** 8人全員のLittle Legendアイコン＋HP。クリックで相手盤面を偵察。Tabキーで全員HP一覧

## 3. 実際の操作感・ゲームフロー

### 1ラウンドの流れ

1. **準備フェーズ(時間制限あり)**: ショップから購入(ドラッグでベンチ→盤面)／盤面上でユニット再配置／XP購入／ショップリロール／アイテム装着(ドラッグ)／ユニット売却(ショップ枠にドラッグで戻す)
2. **戦闘フェーズ**: 自動進行。ユニットは最も近い敵へ移動、射程内で通常攻撃、マナ満タンでスキル発動
3. **結果**: 負けると自HPが減る。**被ダメ = ステージ基礎値 + 生存敵ユニット数(1体1ダメージ、スター無関係)**
   - ステージ2: 基礎0 ／ ステージ3: 基礎2 ／ ステージ4: 基礎5 ／ ステージ5: 基礎8 ／ ステージ6+: 12〜15+

### ステージ/ラウンド構成

- 「ステージ-ラウンド」表記(2-1, 2-2…)。各ステージ頭などに**PvE(モンスター)ラウンド**、ステージ境界に**キャロセル(共有ドラフト: 全員が回転台からユニット＋素材付きを1体選ぶ)**

### 経済(ゴールド)ルール

- **基礎収入**: 序盤ランプ(2/2/3/4ゴールド)→ 2-2以降は**毎ラウンド5ゴールド**
- **利子**: 所持10ゴールドごとに+1、**最大+5**(＝50ゴールドで打ち止め、それ以上の貯金は無駄)
- **PvP勝利**: +1
- **連勝/連敗ボーナス**: 3〜4連=+1／5連=+2／6連以上=+3(勝ち負けどちらの連続でも付く)
- 売却は購入額が戻る(3★等一部例外あり)

### レベル/XP

- 開始Lv1、最大Lv10(一部Set/モードでLv11)。**Lvごとに盤面配置上限が1体増える**(Lv=配置数)
- 受動: ラウンド開始時 自動+2XP ／ 能動: 4ゴールドで+4XP
- Lv到達に必要な累積XP: Lv2=2 / 3=8 / 4=18 / 5=38 / 6=74 / 7=122 / 8=194 / 9=278 / 10=378

### プール(全8人で共有・有限)

- 1コスト: 各30枚 ／ 2コスト: 25 ／ 3コスト: 18 ／ 4コスト: 10 ／ 5コスト: 9
- 誰かが買うと残数が減り、その分ショップ出現率も実効的に下がる

## 補足(このプロジェクトとの対応メモ)

- 本家の `UnitDef` 相当＝ティア+特性タグ配列+スキル(星別3値) / `TraitDef` 相当＝ブレイクポイント配列 という構造は既存コードの `UnitDef`/`TraitDef`/`ItemDef` と方向性が一致
- 本家アイテムは「素材2個→45完成品」の決定論テーブル方式。CLAUDE.mdにある `ItemSystem` の毎ラウンド再計算方式とは別に、合成レシピテーブルの持ち方が参考になる
- UI残タスクへの直接対応: ショップUI＝下部5枠+リロール(2g)+ロック / 盤面UI＝手前ヘックスのみ配置可+ドラッグ移動 / ゴールド・XP表示＝下中央にゴールド/XPバー/レベル/HPを集約 / 特性パネル＝左側に「発動中は上・ハイライト、未発動は下・ディム」＋人数/閾値表示
